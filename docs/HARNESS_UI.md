# AIハーネスUIの構成

このカタログはハーネスへ組み込むReact UIを提供する。AI実行エンジン・権限管理・音声認識・ファイルストレージは利用側から接続する。

## 必要な画面と責務

| 領域 | 提供部品 | 振る舞いと接続先 |
| --- | --- | --- |
| 入力 | AIComposer | controlled入力、IMEを考慮した送信、改行、送信停止、空入力の抑制 |
| ファイル | FileAttachmentButton / AttachmentList | File選択、Composerでドロップ・貼り付け、削除、添付状態、件数・サイズ上限。アップロードはonFilesから接続 |
| 音声 | VoiceInputButton | idle/listening/processing/error。マイク許可・録音・認識・キャンセルは呼び出し側が管理 |
| モデル | ModelPicker | 候補をアプリ側から供給。選択状態、無効候補、キーボード操作 |
| コンテキスト | CommandList / CommandPalette | @によるファイル・エージェント参照、/によるSkill・操作。検索、上下/Home/End、Enter、Escape |
| 会話管理 | ChatSidebar / ConversationToolbar | 追加・検索・選択・ピン留め・削除・設定・コマンド呼び出し |
| 応答 | ChatMessage | user/assistant、生成中表示、コピー、編集、再生成要求。テキストを安全に表示 |
| 実行 | RunStatus / ToolRun | 待機・実行・承認待ち・成功・失敗・停止、ツール出力の開閉、再試行要求 |
| 承認 | ApprovalCard | 操作内容・理由・コマンドを表示し、今回のみ許可／拒否。UIだけでは権限を付与しない |
| 成果物 | ArtifactCard | ファイル名、説明、開く、ダウンロード。内容とファイルURLは利用側が管理 |
| 使用量 | ContextUsage | 実測token数と上限を表示。モデルの上限や消費量を推測しない |
| 設定 | HarnessSettingsの組み合わせ例 | モデル・推論量・承認方針。一般部品で組み立てる |

## 入力の契約

`AIComposer`の本文は`value` / `onValueChange`で管理する。`onSend`は送信要求を通知する。送信完了の判定、添付のアップロード、本文のクリア、サーバーのキャンセルは利用側が担当する。`running`中は送信を停止ボタンに置き換え、`onStop`未指定なら停止操作を無効にする。

- Enter: 送信。Shift + Enter: 改行。IME変換中は候補決定・送信をしない。
- カーソル直前の`@` / `/`を検出し、現在のトークンだけを置き換える。
- コマンドの`value`には`@filename`や`/review`のように挿入する文字列を指定する。
- `onCommandSelect`で選択後のアプリ処理を接続できる。勝手に外部ツールを実行しない。
- 初期上限は10ファイル・1件20MiB。制限はpropsで変更可能。サーバー側の検証も別途必要。
- uploading/errorの添付がある間は送信不可。readyは呼び出し側が決定する。
- 内容を生HTMLとして扱わない。添付内容もこのUI内では解釈しない。

## アイコン

ユーザー提供の画像を基準に、24px viewBox、線幅2.6、丸い端と接合部を採用。チェックの形は`M5 12l4 4L19 6`。チェックボックスは視認性を保つため線幅3。SVGは装飾として読み上げから除外し、アイコンボタン側にアクセシブルな名前を付ける。

## ローカルデモの範囲

`HarnessWorkspace`は部品の組み合わせ例であり、UIパッケージの単独コンポーネントではない。会話はReact stateに保存し、更新すると消える。応答は「ローカルUIデモ」と明示した固定文を表示する。音声ボタンは状態見本のみで、マイクアクセス・録音をしない。添付ファイルは名前・サイズの見本を保持し、外部へ送信しない。モデル名は例示であり、特定サービスの提供モデルを表さない。

実サービス接続時には、ストリーム購読解除、停止リクエスト、エラー処理、音声ストリーム解放、権限のサーバー側検証、会話永続化、添付アップロードの取消をアプリ側で実装する。Safari／Firefox、実際のIME・音声・支援技術での最終確認は未完了。
